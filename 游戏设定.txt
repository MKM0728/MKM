========================================
   Roguelike Dungeon 游戏设定
   Ver 0.2.0
========================================

【技术栈】
  语言：Java 17
  引擎：FXGL 17.3 + JavaFX 20
  构建：Gradle 9.4.1 (fatJar)
  测试：JUnit 5
  架构：ECS (Entity/Component/System)

【游戏画面】
  屏幕分辨率：960 x 640 像素
  瓦片大小：32 x 32 像素
  可视区域：30 x 20 瓦片
  像素网格：3px 像素块 (11x11 精灵)
  视角：360 度射线 FOV，半径 8 格
  亮度调节：设置菜单中可调节画面亮度

【地图系统】
  楼层数：3
  地图生成：BSP 算法，深度 5
  地图大小 (1:2:4 比例)：
    第1层：30 x 20
    第2层：60 x 40
    第3层：120 x 80
  最小房间尺寸：5 格
  走廊连接：
    - BSP 兄弟节点 L 型走廊（基础连接）
    - 额外随机走廊：30% 概率连接非兄弟房间（四通八达）
  瓦片类型：WALL(墙) / FLOOR(地面) / CORRIDOR(走廊) / DOOR(门) / STAIRS_DOWN(下行楼梯) / WATER(水)

【玩家】
  初始 HP：100
  移动速度：2 (每回合移2格)
  出生点：第一间房间中心 (楼梯上)
  移动方式：D-pad 按钮长按 / 鼠标点击相邻格
  移动动画：TranslateTransition 平滑过渡 (75ms/步)

【敌人】
  红蝙蝠 (Bat)：
    血量：30 / ATK：5 / DEF：0 / SPD：7
    移速：1.5 / 击杀经验：8
    颜色：红色身体 + 亮红翅膀
    特性：扇翅动画，飞行移动

  紫骷髅人 (Skeleton)：
    血量：60 / ATK：10 / DEF：2 / SPD：5
    移速：1.0 / 击杀经验：12
    颜色：紫色身体
    特性：走腿动画，地面移动

  白幽灵 (Ghost)：
    血量：120 / ATK：15 / DEF：0 / SPD：6
    移速：0.8 / 击杀经验：25
    颜色：白色半透明身体 + 暗色空洞眼 + 飘浮波浪下摆
    特性：
      - 每层仅 1 只，放置在通往宝箱的必经之路上
      - 进入幽灵房间后，所有出入口被关闭（走廊变墙）
      - 击杀幽灵后，封锁解除，可继续通行
      - 掉落率 60%，随机掉落镰刀/宝剑/斧头

  楼层敌人数量 (1:1.5:2 比例)：
    第1层：6 只普通敌人 + 1 只幽灵 = 7 只
    第2层：9 只普通敌人 + 1 只幽灵 = 10 只
    第3层：12 只普通敌人 + 1 只幽灵 = 13 只
  类型分布：蝙蝠/骷髅随机 50/50

  敌人AI (行为树)：
    - 看到玩家且相邻 → 近战攻击
    - 看到玩家且距离 ≤8 + 有视线 → 追击 (A* 寻路)
    - 低血量 → 逃跑
    - 未发现玩家 → 随机游荡

【武器系统】
  拳头 (Fists)：伤害 5，初始装备，不掉落
    攻击特效：黄色闪光
  镰刀 (Sickle)：伤害 10，蝙蝠 40% 掉落 (50%概率)
    攻击特效：银色弧光闪烁
  宝剑 (Sword)：伤害 15，蝙蝠/骷髅 40% 掉落 (各50%概率)
    攻击特效：金光爆发
  斧头 (Axe)：伤害 30，骷髅 40% 掉落 (50%概率)
    攻击特效：橙红色冲击 + 屏幕震动

  掉落规则：
    - 蝙蝠掉落：镰刀 或 宝剑 (各50%)，掉落率 40%
    - 骷髅掉落：宝剑 或 斧头 (各50%)，掉落率 40%
    - 幽灵掉落：镰刀/宝剑/斧头 (各33%)，掉落率 60%

  武器像素：
    - 镰刀：弯刀弧形 + 短柄，银灰色
    - 宝剑：直刃 + 金色十字护手 + 棕色握柄
    - 斧头：宽刃头 + 长柄，银灰色
    - 地面掉落：发光渲染

  战斗伤害计算：
    - 玩家攻敌 = 装备武器伤害 (直接伤害，无视防御)
    - 敌人攻玩家 = ATK - 玩家DEF (通过DamageCalculator)

【宝箱系统】
  像素：棕色箱体 + 金色盖子 + 金色锁 + 白色闪光
  生成位置：远离出生点 (>地图半对角线)，地面格，无敌人
  拾取判定：角色走到宝箱格子上
  房间方向提示：进入新房间时显示金色箭头指向宝箱方向，并浮动提示文字
  第1-2层：拾取 → 楼层过渡 (1.5秒提示) → 进入下层
  第3层：拾取 → 最终通关

【幽灵房间封锁机制】
  触发条件：玩家进入幽灵所在房间
  封锁效果：
    - 扫描房间边界相邻的走廊/门瓦片
    - 将其替换为墙壁 (WALL)
    - 显示 "LOCKED!" 白色浮动文字
    - 玩家无法走出幽灵房间
  解锁条件：击杀幽灵
  解锁效果：
    - 恢复所有被封锁的瓦片
    - 显示 "UNLOCKED!" 绿色浮动文字
    - 玩家可自由通行

【楼层过渡】
  机制：PauseTransition 1.5 秒显示 "Floor X - Go deeper!"
  安全措施：
    - 过渡期间游戏状态设为 MENU，阻止游戏循环
    - 进入新楼层时重置输入状态 (holdDir/animating)
    - 渲染时防御性数组越界检查

【状态栏 (HUD)】
  左上角：
    - HP：当前血量/最大血量 (绿色，HP<30% 变红)
    - Weapon：当前装备武器名称 (金色)
    - Floor：当前楼层
  右上角：
    - Turns：回合数

【设置菜单】
  入口：右上角 ⚙ 齿轮按钮
  功能：
    1. 亮度调节 (Brightness)
       - 滑块范围：-80% ~ +80%
       - 实时预览，使用 ColorAdjust 效果
    2. 游戏指南 (Game Guide)
       - 敌人介绍：显示所有敌人血量/攻击/特性/掉落
       - 武器介绍：显示所有武器伤害/特效/掉落来源
       - 玩法说明：操作方式/目标/技巧
    3. 返回主菜单 (Return to Main Menu)
  打开设置时游戏自动暂停 (PAUSED 状态)

【存档系统】
  自动存档：auto
  存档内容：
    - 楼层、种子、玩家位置/血量/属性
    - 装备武器、回合数、击杀数
    - 敌人位置/类型/血量/存活状态
    - 地面武器位置/类型
    - 幽灵房间位置/封锁状态
  存档时机：
    - 每 10 秒自动存档
    - 楼层过渡时存档
    - 武器拾取后下次自动存档
  存档位置：~/.roguelike-dungeon/auto.json
  读档：主菜单 Continue 按钮（有存档时启用）
  删档：新游戏开始时 / 死亡时 / 通关时

【菜单与流程】
  主菜单：New Game / Continue(有存档时可用) / Exit
  游戏结束：显示楼层/击杀/回合数 → Try Again / Main Menu
  胜利画面：显示 "YOU WIN!" + 统计信息 → Play Again

【操作方式】
  D-pad 按钮 (屏幕底部)：▲▼◀▶ 长按连续移动 + 攻击
  鼠标点击：点击相邻格子单步移动/攻击
  设置按钮 (右上角)：⚙ 打开设置菜单
  攻击方式：移动到敌人所在格子 = 攻击
  拾取武器：走到武器所在格子自动拾取并装备
